# Shapes the context docs do not own

Component stanzas, routes, OIDC, secrets, and storage live in `docs/context/`. This file
holds only the file shapes no context file covers.

## Config file rendered with secrets (ESO `templateFrom`)

Reference: `kubernetes/apps/default/immich` — copy its `app/kustomization.yaml`, its
`resources/` directory, and the ExternalSecret's `templateFrom` block.

Immich's app kustomization is a Component (`kind: Component`,
`apiVersion: kustomize.config.k8s.io/v1alpha1`) with a `configMapGenerator` for the template
file, `configurations` pointing at `resources/kustomizeconfig.yaml`, and
`generatorOptions.disableNameSuffixHash: true`.

`resources/kustomizeconfig.yaml` is a `nameReference` for `ConfigMap` whose only field spec
is `spec/target/template/templateFrom/configMap/name` on `ExternalSecret`. The template file
may use Go template syntax and `${…}` substitutions.

## Config file mounted as-is

Reference: `kubernetes/apps/observability/karma` — a plain `configMapGenerator` with
`generatorOptions.disableNameSuffixHash: true`, mounted through `persistence` with
`type: configMap`. No `kustomizeconfig.yaml` is needed when nothing rewrites the name.

## Script files kept byte-exact

Reference: `kubernetes/apps/media/sonarr`.

A `configMapGenerator` whose files are shell scripts needs
`generatorOptions.annotations.kustomize.toolkit.fluxcd.io/substitute: disabled`; otherwise
Flux substitutes `$` and `${…}` inside the scripts and corrupts them. Mount the generated
ConfigMap through `persistence` with `type: configMap`, `defaultMode: 0775`, and
`readOnly: true`.

## Custom OCI chart

Reference: `kubernetes/apps/network/echo` (a chart from `ghcr.io/home-operations/charts`).

- `app/ocirepository.yaml` points at the chart: `url: oci://{registry}/{chart}`, with
  `ref.tag` from the upstream release.
- `app/helmrelease.yaml` uses `chartRef` to that OCIRepository. Values follow the chart's own
  schema, not app-template.
- No values are generated by this skill. Read the chart's values from upstream; if they are
  unknown, stop and say so.

Charts not on GHCR resolve through the private `ocharted` proxy — see `CONTEXT.md` →
ocharted. A workstation needs `just kube registry-auth` before rendering them.
